# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added

- Support and verification for PHP 8.5, including PHP 8.5.11.
- PHPUnit tests and PHPStan level 8 static analysis.
- MIT license and complete Composer package metadata.

### Changed

- Require PHP 8.3 or newer.
- Update Slim to 4.15 and Slim PSR-7 to 1.8 for PHP 8.5 compatibility.
- Use the `WebSK\\` PSR-4 namespace prefix.

### Security

- Update Slim to a release containing the `HtmlErrorRenderer` XSS fix.
